# Ses efektleri

Varsayılan efektler, `npm install` ile gelen HyperFrames paketindeki 21 dosyalık kütüphaneden
okunur (`node_modules/hyperframes/dist/skills/media-use/audio/assets/sfx/`, Pixabay Content License:
ticari kullanım serbest, atıf gerekmez). Dosyalar bu repoya kopyalanmaz.

Kendi efektlerinizi buraya aynı adla (`whoosh.mp3`, `pop.mp3`, `riser.mp3`, `impact-bass-1.mp3` …)
koyarsanız önceliklidir. Yalnızca kullanım izniniz olan sesleri ekleyin.

Kurgu, efektleri ekrandaki olaylara bağlar: sahne geçişi → whoosh, sayı/rozet → pop,
ödül sahnesi → riser + impact (filmde bir kez).
